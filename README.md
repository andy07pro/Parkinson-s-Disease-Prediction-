# Parkinson-s-Disease-Prediction-
# Parkinson's Disease Detection using Machine Learning

This repository contains a comprehensive implementation of various machine learning and deep learning models to classify individuals as Parkinson's Disease (PD) positive or negative based on specific vocal features.

## Features of the Project

1. **Dataset**: The dataset used includes features related to vocal measurements and a target label (`status`) indicating PD positive (1) or negative (0). Ensure to replace the placeholder path with your actual dataset file.

2. **Algorithms Implemented**:
   - **XGBoost Classifier**: Achieves high accuracy using gradient-boosting techniques.
   - **Random Forest Classifier**: Employs ensemble methods for better performance.
   - **KMeans Clustering**: Used for unsupervised classification of PD status.
   - **Support Vector Machine (SVM)**: Implements supervised classification.
   - **Gradient Boosting Classifier**: A boosting algorithm for prediction accuracy.
   - **Decision Tree Classifier**: A simple and interpretable classifier.
   - **Artificial Neural Networks (ANN)**: Multi-layer perceptron implementation.
   - **Convolutional Neural Networks (CNN)**: Utilizes sequential layers for feature extraction and classification.

3. **Evaluation Metrics**:
   - Accuracy Score
   - Confusion Matrix
   - Classification Report (Precision, Recall, F1-Score)
   - ROC Curve and AUC

4. **Visualization**:
   - Histograms and distribution plots of key features.
   - Heatmaps showing feature correlations.
   - ROC curve for model evaluation.
   - Confusion Matrix visualization.
